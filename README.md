## 🔁 Cómo se actualiza

1. Revisar fuentes oficiales (Rockstar Newswire) y medios de [`fuentes.md`](noticias/fuentes.md).
2. Crear una nota nueva con la [plantilla](recursos/plantilla-noticia.md).
3. Etiquetar cada dato: ✅, 📰 o 🔮.
4. Registrar el cambio en el [CHANGELOG](CHANGELOG.md) y hacer commit.

## 🧭 Principios editoriales

- **Fuentes antes que velocidad:** ningún dato sin fuente.
- **Nada de filtraciones:** no se comparten ni se enlazan clips o archivos filtrados.
- **Contenido original:** el texto es propio. Las citas son breves y llevan atribución.
- **Imágenes:** solo gameplay capturado por la autora o material permitido por la política de Rockstar.
